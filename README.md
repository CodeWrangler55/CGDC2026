# CGDC2026

Static micro website for CGDC2026.

## Local preview

Open `index.html` in a browser, or serve the folder with any static web server.

## GitHub Pages

This project includes a GitHub Actions workflow at `.github/workflows/pages.yml`.
After the repository is pushed to GitHub:

1. Open the repository settings on GitHub.
2. Go to **Pages**.
3. Set **Source** to **GitHub Actions**.
4. Push to `main`.

The workflow publishes this repository root as the Pages site.
